# Hallmark Anti-AI Design Standards — Property Gateway
## Powered by nutlope/hallmark & Strategy 360

This project enforces the **Hallmark** design standard (created by Hassan El Mghari / nutlope) to guarantee that **Property Gateway** looks human-designed, bespoke, and authoritative—eliminating the generic, repetitive templates typically generated by AI models.

---

## 1. The Hallmark Hard Floor (Non-Negotiable Rules)

Every single component, stylesheet, and layout in Property Gateway must adhere to these 16 hard rules:

1. **Tokens Only:** Every color and font must go through a declared design token (Tailwind theme or `:root` variables). Never hardcode literal hex colors or one-off font families in components.
2. **Never `transition: all`:** Never animate `width`, `height`, `top`, or `left`. Only animate composited properties (`transform`, `opacity`, `box-shadow`).
3. **No Italic Accent Words:** Never wrap a single word in a headline with italics or an isolated gradient.
4. **`overflow-x: clip`:** Use `overflow-x: clip` on both `html` and `body`. Never use `overflow-x: hidden`, and never use `100vw`.
5. **Robust Grid Tracks:** Image-bearing grids must use `minmax(0, 1fr)`. Headings must specify `overflow-wrap: break-word; min-width: 0` to prevent horizontal blowouts.
6. **Instant Keyboard Focus:** Every interactive element must feature a visible `:focus-visible` ring.
7. **Accessibility & Reduced Motion:** Every animation must respect `prefers-reduced-motion: reduce`. The page must remain readable and functional with scripting disabled.
8. **Zero Fabricated Proof:** Never invent fake metrics ("10,000+ happy buyers"), fake testimonials, or placeholder logo walls. Use only real project data.
9. **No Uppercase Eyebrows:** Avoid small tracked uppercase labels like `01 / AMENITIES`. Keep labels in sentence case at normal tracking.
10. **No Glued Punctuation:** Never use middle-dot-joined metadata (`Flat · 3 BHK · OMR`) or glue arrows to link text (`View Details->`).
11. **Strict Cliché Ban:** Never use purple-to-cyan crypto gradients, cards nested inside cards, emojis as UI icons, or artificial window chrome.
12. **The 1280×800 Viewport Rule:** The hero headline, single sentence, and primary call-to-action must all be visible at 1280×800 without scrolling.
13. **Concise Copy Rhythm:** Cap text density to roughly 80 words on any single viewport screen.
14. **Capped Container:** Max-width containers (`max-w-7xl mx-auto px-6`) are capped and centered. On 1920px+ monitors, side gutters grow—text measures and card grids do not stretch uncontrollably.
15. **Linter Verification:** Run `sloplint.mjs` to automatically catch and eliminate AI slop patterns.

## 2. Real Estate Application for Property Gateway

* **Authentic Chennai Materials:** Visuals and copy highlight real Chennai micro-markets (OMR, ECR, Anna Nagar, Guindy, Porur) and real RERA registration details.
* **Hero Section:** Clean, architectural photography, crisp typography, and an immediate sticky search bar.
* **Conversion CTAs:** Clear WhatsApp floating action button and click-to-call, free of manipulative pop-up clutter.
